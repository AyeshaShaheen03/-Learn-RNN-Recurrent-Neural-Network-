Section 1

What is an RNN? (no math yet)

An RNN is a neural network that reads one word at a time and keeps a tiny "memory" of what it already read. Watch the reader below think as each word arrives.

Intuition: the thought-bubble (hidden state) keeps updating. Each new word combines with the old memory to form a new memory.
Section 2

How a word becomes a vector

Computers don't understand "hello". We turn it into numbers in three steps.

Step 1 — Tokenize: the word gets an ID
Step 2 — Embed: the ID becomes a dense vector
Step 3 — Feed: the vector enters the RNN cell
Section 3

Inside the RNN cell (with math)

The cell mixes the new input with the previous memory, squashes the result, and produces a new memory.

ht = tanh( Wxh · xt + Whh · ht-1 + bh )
yt = Why · ht + by
Wxh · xt — "how much does the new word matter?"
Whh · ht-1 — "how much of the old memory do we keep?"
bh — "a small nudge so the cell isn't stuck at zero."
tanh(…) — "squash the result between -1 and +1 so it doesn't explode."
yt — "turn the memory into a prediction."
Section 4

Activation functions — the squashers

The dot slides along the input axis; the output follows the curve. This is what "squashing" actually looks like.

sigmoid

Output in (0, 1). Great for gates.

tanh

Output in (-1, 1). Default in classic RNN.

ReLU

Output in [0, ∞). Rare in RNN — can blow up.

The vanishing gradient — seen, not just told

During training, the "lesson" travels backward in time. In a plain RNN it gets quieter at every step. In an LSTM the gate keeps it loud.

LSTM with gates — gradient survives:

In plain English: the further back we go, the quieter the lesson becomes. The early words never learn that they mattered.
